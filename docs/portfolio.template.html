05 / ENGINEERING TRADEOFFS

Boundaries are
part of the design.

The build is intentionally compact. Its guarantees are specific, and the operational gaps are documented.

⤳

Queue the work.

HTTP returns 202 after enqueue. Bedrock work runs in a separate Lambda with a 180-second timeout; SQS visibility is 18 minutes.

◇

Constrain execution.

Two allowlisted tools, typed arguments and citation checks. No browsing, shell execution, vector database or additional agents.

↻

Document the recovery gap.

Delivery is at least once. Conditional claims skip duplicates, but a crash after claim can strand a RUNNING record. Automatic recovery is deferred.

▤

Own the offboarding.

DynamoDB is retained on stack deletion. Amplify and GitHub Pages have separate lifecycles. Alarms have no notification subscriptions configured.
